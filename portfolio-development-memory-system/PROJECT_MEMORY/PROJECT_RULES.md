# PROJECT RULES

## Строгие запреты

❌ Запрещено придумывать проекты  
❌ Запрещено увеличивать показатели  
❌ Запрещено добавлять несуществующий опыт  
❌ Запрещено писать ложные результаты  
❌ Запрещено менять цифры  
❌ Запрещено удалять существующие проекты  
❌ Запрещено удалять ссылки  
❌ Запрещено заменять данные без указания владельца  
❌ Запрещено сокращать описания  
❌ Запрещено добавлять: Senior Developer, Expert, 10 лет опыта  

## Правила работы с проектом

### Перед любым изменением:
1. Прочитать PROJECT_MEMORY.md
2. Показать список изменяемых файлов
3. Сохранить все старые данные
4. Не изменять дизайн без указания владельца

### Добавление новых проектов:
- Только через src/data/projects.json
- Не изменять компоненты
- Не удалять существующие записи

### Добавление изображений:
- Только внешние URL
- Хранить в src/data/gallery.json или media.json
- Не скачивать изображения локально

### Изменение данных:
- Все данные хранятся в src/data/*.json
- Компоненты только отображают данные
- JSON — единственный источник данных

## Принцип работы
"Это живое портфолио. Оно должно постоянно расширяться новыми проектами, скриншотами, ссылками и результатами без потери существующей информации."
